# SRS简化版需求规格

**Story ID**: US001  
**Story标题**: 用户登录系统  
**生成时间**: 2026-04-25

---

## 1. 功能概述

**功能描述**: 用户使用账号密码登录系统，验证身份后获取访问权限，支持"记住我"功能保持长期会话。

**来源AC**: AC1（正常登录）、AC2（记住我）、AC3（密码错误）、AC4（账号锁定）、AC5（Token过期）

---

## 2. 输入验证需求

| 输入项 | 数据类型 | 必填 | 来源AC | 验证规则 | 错误提示 |
|--------|---------|------|--------|---------|---------|
| 账号（用户名/邮箱） | 字符串 | 是 | AC1, 边界条件 | 不能为空；如果是邮箱需符合RFC标准格式 | "请输入账号" / "邮箱格式不正确" |
| 密码 | 字符串 | 是 | AC1, 边界条件 | 不能为空 | "请输入密码" |
| 记住我 | 布尔值 | 否 | AC2 | 可选值：true/false | - |
| IP地址 | 字符串 | 是（系统自动获取） | AC1 | 系统自动获取客户端IP地址 | - |

**说明**: 
- 账号支持用户名或邮箱格式，系统根据输入内容自动识别
- 密码在传输前需加密（由技术层实现）
- IP地址由系统自动获取，用于记录审计日志和账号锁定

---

## 3. 输出数据需求

### 3.1 成功场景输出

**来源AC**: AC1（正常登录）、AC2（记住我）

| 数据项 | 数据类型 | 说明 | 来源AC描述 |
|--------|---------|------|-----------|
| 认证令牌 | 字符串 | 用户身份验证令牌，短期有效（30分钟）或长期有效（7天） | AC1: JWT Token（有效期30分钟）；AC2: 长期Token（有效期7天） |
| 用户姓名 | 字符串 | 当前登录用户的姓名 | AC1: 顶部导航栏显示用户姓名和头像 |
| 用户头像 | 字符串 | 用户头像图片地址或标识 | AC1: 顶部导航栏显示用户姓名和头像 |
| 跳转目标页面 | 字符串 | 登录成功后跳转的页面路径 | AC1: 页面自动跳转到任务列表页（/tasks） |
| 审计日志记录 | 对象 | 记录登录操作的审计信息 | AC1: 登录操作记录到审计日志（时间戳、IP地址、操作结果："成功"） |

**示例说明**: 
- 正常登录（未勾选记住我）：返回30分钟有效期的认证令牌，用户姓名，用户头像，跳转路径为/tasks
- 正常登录（勾选记住我）：返回7天有效期的认证令牌，用户姓名，用户头像，跳转路径为/tasks

### 3.2 错误场景输出

| 错误场景 | 来源AC | 错误提示内容 | 额外说明 |
|---------|--------|-------------|---------|
| 密码错误 | AC3 | "账号或密码错误" | 错误提示3秒后自动消失；记录审计日志（操作结果："失败 - 密码错误"） |
| 账号被锁定 | AC4 | "您的账号因多次登录失败已被锁定30分钟，请稍后再试" | 账号状态变更为"临时锁定"；30分钟后自动解锁；记录审计日志（操作结果："账号锁定"） |
| Token过期 | AC5 | "登录已过期，请重新登录" | 清除本地存储的过期Token；跳转到登录页 |
| 账号为空 | 边界条件 | "请输入账号" | 禁用登录按钮 |
| 密码为空 | 边界条件 | "请输入密码" | 禁用登录按钮 |
| 邮箱格式错误 | 边界条件 | "邮箱格式不正确" | - |
| 锁定期间尝试登录 | 边界条件 | "账号已锁定，剩余X分钟" | X为剩余锁定时间（动态计算） |

## 5. 补充说明

### 边界条件

**输入验证**:
- 账号输入框为空时，显示"请输入账号"提示，禁用登录按钮
- 密码输入框为空时，显示"请输入密码"提示，禁用登录按钮
- 如果账号输入为邮箱格式，需验证邮箱格式合法性（如"test@"为不合法格式）
- 支持密码可见性切换（明文/密文），由前端实现

**账号锁定逻辑**:
- 用户在30分钟内连续登录失败5次，系统自动锁定账号30分钟
- 锁定期间该账号无法登录（即使密码正确）
- 30分钟后账号自动解锁
- 锁定期间尝试登录时，显示剩余锁定时间（动态计算）

**Token管理**:
- 未勾选"记住我"：生成30分钟有效期的短期Token
- 勾选"记住我"：生成7天有效期的长期Token
- Token过期后，用户访问任何功能时系统检测并跳转到登录页
- 跳转前显示Toast提示："登录已过期，请重新登录"
- 清除本地存储的过期Token

**已登录状态处理**:
- 如果用户已登录（Token有效），直接访问/login页面时，自动跳转到任务列表页（/tasks）
- 避免重复登录

### 审计日志需求

**记录内容**:
- 时间戳：登录操作发生的精确时间
- IP地址：客户端IP地址（系统自动获取）
- 操作结果：
  - 成功："成功"
  - 密码错误："失败 - 密码错误"
  - 账号锁定："账号锁定"

**记录时机**:
- 每次登录尝试（成功或失败）都记录到审计日志
- 账号锁定事件单独记录

### 性能需求

- 登录响应时间：P95 < 1秒（从用户点击"登录"按钮到返回结果）
- 并发登录：支持100个用户同时登录，成功率>99%
- Token生成时间：< 100ms
- 密码校验时间：< 200ms（BCrypt加密校验）

### 安全需求

- 密码传输前需加密（具体加密方式由技术层-API设计决定，通常使用HTTPS加密传输）
- 密码存储使用BCrypt加密（由后端实现）
- Token生成使用JWT标准（由后端实现）
- 防止暴力破解：连续5次登录失败锁定账号30分钟
