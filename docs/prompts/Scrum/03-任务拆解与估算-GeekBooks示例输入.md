### US-001：智能图书推荐（8 SP）详细信息

**用户故事**：
- **作为** 注册用户
- **我希望** 在首页看到根据我的浏览和购买历史推荐的图书
- **以便** 我能快速发现感兴趣的新书

**验收标准**：
- [ ] 首页展示"为你推荐"模块，展示6-8本图书
- [ ] 推荐基于用户浏览历史（最近30天）和购买记录
- [ ] 推荐响应时间P95<1秒
- [ ] 推荐点击率≥30%（需A/B测试验证）
- [ ] 支持降级：新用户或数据不足时展示热门图书

**技术约束**：
- 推荐算法：协同过滤（User-based CF）
- 缓存策略：Redis缓存30分钟
- 降级方案：推荐服务不可用时展示热门图书

### US-002：新用户冷启动推荐（5 SP）

**用户故事**：
- **作为** 新注册用户（无浏览和购买历史）
- **我希望** 在首页看到热门/精选图书推荐
- **以便** 我能快速了解平台的图书品类

**验收标准**：
- [ ] 新用户首页展示"热门推荐"模块
- [ ] 推荐基于全站热销榜（最近7天）
- [ ] 支持按品类筛选（编程、算法、AI等）

### US-003：热门榜单管理后台（3 SP）

**用户故事**：
- **作为** 运营人员
- **我希望** 在后台管理系统查看和调整热门榜单
- **以便** 我能手动干预榜单

**验收标准**：
- [ ] 后台展示当前热门榜单（最近7天Top 50）
- [ ] 支持手动置顶图书（最多5本）
- [ ] 支持手动屏蔽图书

---

### US-004：推荐效果反馈（5 SP）

**用户故事**：
- **作为** 注册用户
- **我希望** 对推荐的图书进行"感兴趣"或"不感兴趣"反馈
- **以便** 系统能更准确地了解我的偏好

**验收标准**：
- [ ] 每本推荐图书下方有"👍 感兴趣"和"👎 不感兴趣"按钮
- [ ] 用户点击后，推荐立即刷新
- [ ] 反馈数据写入用户行为日志

**依赖关系**：⚠️ 依赖US-001（智能图书推荐）的推荐服务API
