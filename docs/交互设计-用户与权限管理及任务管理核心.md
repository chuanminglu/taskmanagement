## 📖 文档说明

本文档定义了任务管理系统的完整交互流程、交互反馈机制和状态流转逻辑，为前端开发和测试提供详细的交互规范。

### 文档结构

- **第1章**: PlantUML活动图 - 描述用户旅程的完整交互流程
- **第2章**: 关键交互点说明 - 定义所有页面的交互元素和行为
- **第3章**: 交互反馈设计 - 规范用户操作的反馈机制
- **第4章**: 状态流转定义 - 定义页面和组件的状态机逻辑
- **第5章**: 异常处理和边界条件 - 覆盖错误场景的处理方案

  :assigneeSelector选择负责人;
  note right: 支持搜索，防抖200ms
  :assigneeTaskCount显示"当前任务：5个";
  
  :prioritySelector选择优先级（高/中/低）;
  :dueDatePicker选择截止日期;

      #DANGER:显示errorToast;

    endif

  endif

      :saveButton进入loading状态;

      :记录任务历史（Edit操作）;

### 1.3 通用异常处理流程

```plantuml
@startuml
title 任务管理系统 - 异常处理流程

!define DANGER #F56C6C
!define WARNING #E6A23C

start

if (异常类型?) then (网络错误)
  #DANGER:显示errorToast（5秒）;
  :提示"网络错误，请检查连接";
  :显示retryButton;
  if (用户点击重试?) then (是)
    :重新发起请求;
  else (否)
    :保持错误状态;
  endif
  
else (API超时)
  :请求超时（10秒）;
  #DANGER:显示errorToast;
  :提示"请求超时，请稍后重试";
  :恢复按钮状态;
  
else (权限不足)
  #DANGER:显示errorToast;
  :提示"权限不足，无法执行此操作";
  :跳转到上一页或任务列表页;
  
else (Token过期)
  :检测到401响应;
  :清除本地Token;
  #WARNING:显示Toast（"登录已过期，请重新登录"）;
  :跳转登录页 (/login);
  
else (表单验证失败)
  :高亮错误字段（error状态）;
  :显示validationMessage;
  :禁用submitButton;
  :等待用户修正;
  
else (业务逻辑错误)
  :API返回错误信息;
  #DANGER:显示errorToast;
  :显示后端返回的错误消息;
  :恢复操作前状态;
  
else (文件上传失败)
  #DANGER:显示errorToast;
  :提示"上传失败：{错误原因}";
  :attachmentUpload显示error状态;
  :显示retryButton;
endif

stop

@enduml
```

## 🖱️ 第2章：关键交互点说明

### 2.1 P01: 登录页 (/login)

| 交互元素 | 触发动作 | 响应效果 | 目标状态/跳转 | 防抖/节流 | 关联故事 |
|---------|---------|---------|-------------|----------|---------|
| usernameInput | 输入 | 获得focus状态，蓝色边框 | 输入中 | 无 | US001 |
| usernameInput | 失焦 | 验证邮箱格式，错误显示红色边框 | 验证状态 | 无 | US001 |
| passwordInput | 输入 | 获得focus状态，密文显示 | 输入中 | 无 | US001 |
| passwordVisibilityToggle | 点击 | 切换密码明文/密文显示 | 可见性切换 | 无 | US001 |
| rememberMeCheckbox | 点击 | 选中/取消选中，延长会话时间到7天 | 选中状态 | 无 | US001 |
| loginButton | 点击 | 进入loading状态，禁用输入框，发起API请求 | loading → 成功/失败 | 300ms | US001 |
| loginButton | 成功响应 | 显示成功提示（2秒），跳转任务列表页 | 已登录 | - | US001 |
| loginButton | 失败响应 | 显示errorMessage（3秒），恢复按钮和输入框 | 登录失败 | - | US001 |
| loginButton | 5次失败 | 显示lockoutMessage，禁用所有输入，锁定30分钟 | 账号锁定 | - | US001 |
| forgotPasswordLink | 点击 | 跳转密码重置页（未来功能） | - | 无 | - |

**特殊交互**:
- **Enter键提交**: 在输入框按Enter自动提交登录
- **自动聚焦**: 页面加载后usernameInput自动获得焦点
- **错误自动消失**: errorMessage显示3秒后自动隐藏

| 删除任务 | 创建者/项目经理 | API拒绝请求，返回403 | "❌ 权限不足，无法删除此任务" | 关闭确认弹窗 | US010 |

### 5.4 并发操作处理

| 场景 | 问题描述 | 处理方式 | 用户反馈 | 优先级 |
|-----|---------|---------|---------|--------|
| 快速连续点击提交按钮 | 可能发起多个重复请求 | 防抖300ms，按钮点击后立即disabled | 按钮进入loading状态，禁止再次点击 | P0 |
| 多Tab页同时操作 | 两个Tab页同时编辑同一任务 | 后提交的请求覆盖前一个（乐观锁） | "⚠️ 任务已被其他用户修改，请刷新后重试" | P1 |
| 列表刷新时删除任务 | 刷新请求返回时，任务已被删除 | 前端检测任务ID不存在，从列表移除 | 无提示（静默处理） | P2 |
| 分页切换时筛选条件变更 | 用户修改筛选条件后立即翻页 | 取消上一个请求，发起新请求 | 显示最新筛选结果 | P1 |

## 📚 附录

### A. 防抖与节流时长规范

| 交互类型 | 防抖/节流时长 | 应用场景 | 理由 |
|---------|-------------|---------|------|
| 输入框搜索 | 防抖 300ms | userSearchBox, userFilterDropdown, assigneeSearchBox | 避免每次按键都发起请求，等待用户输入完成 |
| 输入框验证 | 防抖 200ms | taskTitleInput, newPasswordInput, confirmPasswordInput | 实时反馈，但避免过于频繁 |
| 按钮点击 | 防抖 300ms | loginButton, submitButton, saveButton, confirmButton | 防止重复提交，按钮点击后立即disabled |
| 滚动加载 | 节流 500ms | 任务历史懒加载 | 避免快速滚动时频繁触发加载 |

### B. API请求超时设置

| 请求类型 | 超时时长 | 超时处理 |
|---------|---------|---------|
| 登录请求 | 10秒 | 显示errorToast，恢复按钮状态 |
| 列表查询 | 10秒 | 显示errorToast，保持骨架屏 |
| CRUD操作 | 10秒 | 显示errorToast，恢复按钮状态 |
| 文件上传 | 60秒 | 显示errorToast，显示retryButton |
| 审计日志查询 | 15秒 | 显示errorToast，保持骨架屏 |

### C. Toast提示持续时间规范

| 提示类型 | 持续时间 | 关闭方式 |
|---------|---------|---------|
| 成功提示（Success） | 2-3秒 | 自动消失 |
| 错误提示（Error） | 5秒 | 手动关闭或自动消失 |
| 警告提示（Warning） | 5秒 | 手动关闭或自动消失 |
| 信息提示（Info） | 3秒 | 自动消失 |
| 加载提示（Loading） | 直到操作完成 | API响应后自动消失 |
