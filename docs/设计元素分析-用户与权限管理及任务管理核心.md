### 1.2 页面层级关系

```
系统入口
│
├─ P01: 登录页 (/login) 
│   └─ 登录成功 → 根据角色跳转
│       ├─ 管理员 → P02: 用户管理页 或 P06: 任务列表页
│       └─ 成员 → P06: 任务列表页
│
├─ 管理员功能区
│   ├─ P02: 用户管理页 (/admin/users)
│   │   ├─ 新建用户 → 模态框表单
│   │   └─ 编辑用户 → P03: 用户编辑页
│   │
│   ├─ P03: 用户编辑页 (/admin/users/:id/edit)
│   │   └─ 保存返回 → P02: 用户管理页
│   │
│   └─ P04: 审计日志页 (/admin/audit-logs)
│       └─ 查看详情 → 模态框展示
│
├─ 任务管理功能区
│   ├─ P06: 任务列表页 (/tasks) **主工作台**
│   │   ├─ 创建任务 → P07: 任务创建页
│   │   └─ 点击任务 → P08: 任务详情页
│   │
│   ├─ P07: 任务创建页 (/tasks/create)
│   │   └─ 创建成功 → P06: 任务列表页
│   │
│   └─ P08: 任务详情页 (/tasks/:id)
│       ├─ 查看历史 → P09: 任务历史页（标签切换）
│       ├─ 编辑任务 → 模态框表单
│       └─ 删除任务 → 确认弹窗 → P06: 任务列表页
│
└─ 个人设置功能区
    └─ P05: 个人设置页 (/settings/security)
        └─ 密码修改成功 → P01: 登录页（强制重新登录）
```

| 提示框 | validationMessage | 显示密码验证规则 | 默认（灰色）/error（红色） | US004 |
| 按钮 | submitButton | 提交修改 | 默认/hover/loading/disabled（密码强度弱或不一致） | US004 |

| Toast提示 | errorToast | 显示错误信息（旧密码错误/新密码与旧密码相同） | 隐藏/显示 | US004 |

**密码强度检查规则**:
- **弱**: 少于8位 OR 仅数字 OR 仅字母
- **中**: 8位以上，包含字母和数字
- **强**: 9位以上，包含字母、数字和特殊字符

**交互流程**:
1. 用户输入新密码 → passwordStrengthBar实时更新
2. 密码强度为"弱" → submitButton禁用
3. 两次密码不一致 → confirmPasswordInput显示error状态，submitButton禁用
4. 点击提交 → 验证旧密码 → 失败显示errorToast
5. 提交成功 → successToast显示，3秒后跳转P01: 登录页，清除Token
