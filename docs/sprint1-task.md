## US001 — 用户登录系统

> **故事规模**: 5 SP | **Sprint 范围**: 完整实现，无缩减
> **完成时限**: Day 1–5（Week 1）

**用户故事**

> 作为**团队成员 / 项目经理 / 系统管理员**，
> 我希望使用账号密码登录系统，
> 以便安全地访问任务管理系统，保护个人和团队数据不被未授权访问。

**业务规则**

- 密码使用 BCrypt 加密存储，禁止明文
- JWT Token 有效期 30 分钟；勾选"记住我"时颁发 7 天有效期的 Refresh Token
- 连续登录失败 5 次，账号锁定 30 分钟
- Token 过期后，前端任何受保护请求自动跳转登录页

**验收标准**

- [ ] 输入正确账号密码点击登录，1 秒内跳转到任务列表页
- [ ] 输入错误密码，页面显示「账号或密码错误」提示，不泄露具体原因
- [ ] 连续 5 次输入错误密码后，接口返回 423，页面显示「账号已锁定，请 30 分钟后再试」
- [ ] 勾选「记住我」后关闭浏览器再打开，7 天内仍保持登录状态
- [ ] Token 过期后，用户操作任何受保护功能，自动跳转到登录页，登录后返回原页面
- [ ] 登录页面在手机端（375px 宽度）正常显示，表单可正常操作

## US004 — 修改个人密码

> **故事规模**: 3 SP | **Sprint 范围**: 完整实现，无缩减
> **完成时限**: Day 3–5（Week 1）

**用户故事**

> 作为**所有用户**，
> 我希望修改自己的登录密码，
> 以便定期更新密码保障账号安全，或在密码泄露时及时更换。

**业务规则**

- 旧密码验证失败不允许修改
- 新密码不能与旧密码相同
- 新密码强度要求：长度 ≥ 8 位，须同时包含字母和数字
- 密码修改成功后，当前 JWT Token 立即失效，强制重新登录
- 新账号首次登录（`password_changed = false`）强制跳转修改密码页

**验收标准**

- [ ] 输入正确旧密码和符合强度要求的新密码，提交后密码修改成功，Toast 提示「密码修改成功」并跳转登录页
- [ ] 输入错误旧密码，系统显示「旧密码错误」提示，不允许修改
- [ ] 输入弱密码（如 `123456`），实时提示「密码强度不足」，提交被拦截
- [ ] 输入与旧密码相同的新密码，系统显示「新密码不能与旧密码相同」
- [ ] 新账号首次登录，系统强制跳转到修改密码页，完成修改前无法进入其他页面
- [ ] 密码修改成功后，原 Token 调用任何受保护接口返回 401
